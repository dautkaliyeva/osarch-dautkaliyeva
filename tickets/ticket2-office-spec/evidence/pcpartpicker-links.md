**Important Notes regarding PCPartPicker database limitations:**

1.  **Monitors (Accountant & Sales):** For these builds, I selected the **Xiaomi G Pro 27i** monitor in PCPartPicker. I did this because the exact model I used in my budget (Xiaomi A24i) was not available in the PCPartPicker database. I want to clarify that if I had actually purchased the Xiaomi G Pro 27i, the total cost would have exceeded the 3,000,000 KZT budget. Therefore, PCPartPicker was used strictly as a compatibility check, while the actual budget relies on the cheaper Xiaomi A24i monitor as shown in the vendor screenshots.
2.  **Monitor (Web Developer):** For the Web Developer build, the exact **Xiaomi A27Qi** monitor was also missing from the PCPartPicker database. I used a similar 27-inch 2K monitor in PCPartPicker just to verify the power and setup compatibility. The actual model and price are documented in `budget.csv`.
3.  **Operating System (Web Developer):** I did not add an Operating System for the Web Developer build in PCPartPicker because I chose **Ubuntu Linux**. PCPartPicker only lists purchasable hardware and commercial software. Ubuntu is an open-source, freely downloadable OS (0 KZT), which is why it does not appear as a purchased item in the budget. It is legally licensed (under GPL) and highly suitable for web development due to its native support for Docker, local servers, and development tools.
